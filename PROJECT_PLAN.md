# Feed The Nation Project Plan

## Project Summary
Feed The Nation is a large NGO digital platform where users can create accounts, receive support, apply for skills training, apply for jobs, earn and use FTN tokens, invite others through referral codes, buy foodstuffs in Market Square, donate, volunteer, and interact with NGO programs.

## Core Planned Pages
- Home
- About Us
- Campaigns
- Donate
- Volunteer
- Programs
- Skills Training
- Care & Support
- FTN Referral & Token Page
- Market Square
- Jobs / Opportunities
- Impact Stories
- Events
- Blog / News
- Contact
- User Dashboard
- Admin Dashboard

## Global Layout
- Main navbar on every page.
- Secondary horizontal page navigation on every page.
- Footer on every page.
- Fully responsive design.

## Main Design Direction
- Clean NGO design.
- Green, white, soft yellow/orange.
- Rounded cards.
- Soft shadows.
- Mobile-first responsiveness.
- Accessible contrast and readable fonts.
