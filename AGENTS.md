# Feed The Nation Coding Instructions

Feed The Nation is a responsive NGO web platform.

Build the project phase by phase. Do not implement all features at once unless specifically requested.

Frontend rules:
- Use React with Vite.
- Use Tailwind CSS.
- Keep components reusable.
- Use responsive layouts for desktop, tablet, and mobile.
- Use accessible HTML.
- Use clear labels, readable text, good contrast, and alt text for images.
- Use green, white, and soft yellow/orange as the main design direction.
- Keep the design clean, warm, humanitarian, and professional.

Layout rules:
- Every page must use the global header, secondary navigation, and footer.
- The secondary navigation must scroll horizontally on mobile.
- Cards should use rounded corners, spacing, and soft shadows.
- Skills, jobs, support categories, and market products should appear in grid view on desktop and list view on mobile.

Development rules:
- Run the app after major changes.
- Fix build errors before finishing.
- Keep file structure clean.
- Explain what changed after each task.
- Do not add backend features until requested.

Done when:
- AGENTS.md exists.
- The instructions are clear.
- No app functionality is broken.
